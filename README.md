🏎️ F1 Racing Data Analytics using Tableau

📌 Project Overview

This project focuses on analyzing Formula 1 racing data using Tableau to identify championship trends, driver performance, and team performance through interactive data visualizations.

🎯 Objectives

- Analyze Formula 1 championship trends.
- Compare driver and constructor performance.
- Visualize racing statistics using charts and dashboards.
- Present meaningful insights through data analytics.

🛠️ Tools & Technologies

- Tableau – Data visualization and dashboard creation
- Microsoft Excel – Dataset management
- GitHub – Project storage and documentation

📊 Dashboard

The project includes a Tableau dashboard designed to present F1 racing insights in a clear and interactive format.

📁 Project Files

- "F1 racing project final.twbx" – Tableau workbook containing the project visualizations and analysis.

💡 Key Learnings

- Data visualization and analysis
- Dashboard design and formatting
- Identifying trends in racing data
- Presenting analytical insights effectively
